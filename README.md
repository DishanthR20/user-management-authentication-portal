# User Management & Authentication Portal

A Django-based web application for secure user management, authentication, profile management, and QR-code generation.

## Features

### User Features
- User Registration
- User Login
- Profile Management
- Profile Picture Upload
- Password Validation
- Session Handling

### Admin Features
- Admin Creation
- Admin Login
- Add Users
- Update Users
- User List Management

### QR Features
- Dynamic QR Code Generation
- User-specific QR Access

## Tech Stack

- Python
- Django
- PostgreSQL / SQLite
- HTML
- CSS

## Installation

```bash
git clone <repository-url>

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
